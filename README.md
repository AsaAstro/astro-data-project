# Astro Data Project

## About me

I am an Electrical Engineering graduate (M.Sc. in Telecommunications) with a strong interest in astronomy and astrophysics. I am currently building my skills in astronomical data analysis and machine learning, with the goal of pursuing a PhD in this field.

## What is this project?

This project downloads and analyzes real astronomical data from the Gaia space telescope (DR3). It includes sky position plots, color-magnitude diagrams (HR Diagram), and data filtering.

## Data

- Source: Gaia DR3 (gaiadr3.gaia_source)
- 1000 stars
- Columns: source_id, ra, dec, parallax, phot_g_mean_mag, bp_rp

## Tools

- Python 3.14
- pandas
- matplotlib

## What I did

1. Downloaded 1000 stars from Gaia Archive
2. Explored the data with pandas
3. Plotted sky positions (RA vs Dec)
4. Plotted color-magnitude diagram (HR Diagram)
5. Filtered bright and nearby stars
